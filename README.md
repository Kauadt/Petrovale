# Petrovale

Petrovale é um sistema desenvolvido para gerenciar uma rede de postos de combustíveis, criado em 2023 como parte de um projeto multidisciplinar nas disciplinas de **Banco de Dados II**, **Programação de Aplicativos Mobile I** e **Desenvolvimento de Sistemas**, no curso **Técnico em Desenvolvimento de Sistemas** da **ETEC de Registro**.

## 🧩 Visão Geral

O projeto integra diferentes tecnologias para fornecer uma solução completa de gestão:

- **Aplicativo Mobile**: Desenvolvido em **React Native**, com **back-end em PHP**, oferece funcionalidades voltadas ao atendimento e à experiência do usuário final.
- **Aplicação Desktop**: Criada com **Windows Forms (C#)**, voltada para a gestão administrativa e operacional dos postos.
- **Banco de Dados**: Utiliza **MySQL** para armazenamento e gerenciamento das informações.

## ⚙️ Funcionalidades

- Cadastro e consulta de clientes e veículos  
- Controle de abastecimentos  
- Gestão de combustíveis e preços  
- Conta mensal de despesas  
- Agendamento de estacionamento (rotativo ou mensal)  
- Relatórios administrativos  
- Integração entre os sistemas mobile, desktop e banco de dados centralizado  

## 🛠️ Tecnologias Utilizadas

| Componente      | Tecnologia           |
|------------------|----------------------|
| Mobile (front-end) | React Native       |
| Mobile (back-end)  | PHP (API REST)     |
| Desktop           | Windows Forms (C#) |
| Banco de Dados    | MySQL              |


## 🚀 Objetivo Educacional

Este projeto tem como objetivo aplicar, na prática, os conhecimentos adquiridos nas disciplinas técnicas, promovendo a integração entre diferentes áreas do desenvolvimento de software. Ele simula um cenário real de uso em empresas do setor de combustíveis.
